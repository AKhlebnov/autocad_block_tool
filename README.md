## 1. Назначение программы

Программа автоматически нумерует блоки в AutoCAD (камеры, точки доступа, розетки, разъёмы RJ-45 и т.д.) в соответствии с патч-панелями. Для каждого устройства создаётся уникальное имя, например:

```
8.1A1/01.4
```

где:
- `8.1A1` — номер шкафа,
- `01` — номер патч-панели,
- `4` — номер порта на панели.

**Ключевая особенность версии 4.x** — все типы блоков обрабатываются **за один запуск**. Раньше приходилось запускать программу отдельно для каждого типа блока (камеры, затем AP, затем розетки), теперь достаточно задать все настройки один раз.

Для работы необходимо, чтобы каждый блок имел три атрибута:

| Атрибут | Назначение |
|---------|-----------|
| **NAME** | Итоговое имя (заполняется автоматически) |
| **MAC** | Временное поле для номера шкафа (заполняется вручную перед обработкой) |
| **IP** | Временное поле для номера этажа (заполняется вручную перед обработкой) |

> **Примечание:** вместо MAC и IP можно использовать другие атрибуты — они настраиваются во вкладке «Настройки» программы (раздел «Атрибуты блоков и шаблон имени»). По умолчанию используются именно MAC и IP.

## 2. Подготовка чертежа AutoCAD

Перед запуском программы:

1. Откройте нужный чертёж в AutoCAD.
2. Убедитесь, что все блоки имеют атрибуты **MAC** и **IP**.
   - В **MAC** укажите имя шкафа (например, `8.1A1`).
   - В **IP** укажите номер этажа (целое число, например `1`, или дробное, например `1.5` — для сортировки внутри этажа).
3. Заполните эти атрибуты для всех блоков (можно выделить группу блоков и ввести значения через палитру свойств `Ctrl+1`).
4. Сохраните чертёж.

## 3. Запуск программы

Запустите файл `Autocad_tool.exe`. Откроется окно с тремя вкладками: **«Настройки»**, **«Выполнение»** и **«Дополнительно»**.

## 4. Настройки программы

Все настройки задаются в соответствующих полях. При нажатии на любую кнопку настройки **автоматически сохраняются**. Также автосохранение происходит при закрытии окна программы.

### 4.1 Таблица блоков

Вместо одного поля «Имя блока» — **таблица на 5 строк**. В каждой строке:

| Вкл | Имя блока | Отображаемое имя | Диапазоны портов | PoE |
|:---:|-----------|------------------|------------------|:---:|
| ☑ | camera | Видеокамера | 1-18,25-42 | ☑ |
| ☑ | AP | Точка доступа Wi-Fi | 19-23,43-47 | ☑ |
| ☐ | Socket_1p | Розетка | 1-18,25-42 | ☐ |
| ☐ | Socket_RJ-45 | Разъём RJ-45 | 1-18,25-42 | ☐ |
| ☐ | *(пустая строка)* | | | |

- **Галочка** — включает или отключает блок из обработки.
- **Имя блока** — точное имя блока в AutoCAD (`camera`, `AP` и т.д.). Можно выбрать из выпадающего списка или ввести своё.
- **Отображаемое имя** — человекочитаемое имя для кабельного журнала и кроссировочной таблицы (например, «Видеокамера», «Точка доступа Wi-Fi»).
- **Диапазоны портов** — какие порты на патч-панели может занимать этот блок.
- **PoE** — получает ли оборудование этого типа питание PoE. Влияет на столбец «Питание» в кроссировочной таблице.

Кнопка **«+ Добавить строку»** снизу таблицы позволяет добавить дополнительные строки, если в проекте больше 5 типов блоков.

### 4.2 Формат диапазонов портов

Диапазоны и отдельные порты через запятую:

- `1-18,25-42` — порты с 1 по 18 и с 25 по 42,
- `19-23,43-47` — порты с 19 по 23 и с 43 по 47,
- `1,5,10-15` — отдельные порты 1, 5 и диапазон 10–15.

### 4.3 Пропуски портов

Используется, если некоторые порты на конкретных патч-панелях уже заняты другим оборудованием.

**Формат:** каждая строка содержит три части:

```
шкаф, номер_панели, список_портов
```

Примеры:

```
8.1A1,1,25-29
8.1A1,2,25-30,40
```

Это означает:
- в шкафу `8.1A1` на первой панели пропустить порты 25–29,
- в шкафу `8.1A1` на второй панели пропустить порты 25–30 и порт 40.

Поле поддерживает **копирование и вставку** (правой кнопкой мыши).

### 4.4 Максимум патч-панелей в шкафу

Общее поле с предзаполненным значением `20`. Программа не будет искать панели с номером больше указанного.

### 4.5 Особый режим

Особый режим нужен для блоков, которые должны маркироваться **не вместе со всеми**, а **после основных**. Типичный пример — розетки и разъёмы RJ-45.

Параметры:

- **Галочка «Обрабатывать блоки особого режима»** — включает режим.
- **Имена блоков (через запятую)** — какие блоки обрабатывать в особом режиме и в каком порядке.
- **Диапазоны портов** — какие порты могут занимать эти блоки.
- **Галочка «Продолжить с последней патч-панели»** — если включена, особый режим начинается с той же панели, где закончились основные блоки.
- **Поле «Отступить от последнего порта»** — сколько портов пропустить после последнего занятого.

### 4.6 Доназначение нового оборудования

Раздел используется функцией «Промаркировать новое оборудование».

- **Маркер нового блока (`PLACEHOLDER_MARKER`)** — значение атрибута `NAME`, по которому блок считается «новым». По умолчанию — `Пустой`.
- **Галочка «Заполнять свободные порты (дыры)»** — если включена, новые блоки будут занимать освободившиеся порты (например, после удаления старых камер). Если выключена — новые блоки идут строго после последнего занятого порта.

### 4.7 Атрибуты блоков и шаблон имени

| Параметр | Назначение | По умолчанию |
|----------|-----------|--------------|
| **TAG_CABINET** | Имя атрибута с номером шкафа | `MAC` |
| **TAG_FLOOR** | Имя атрибута с номером этажа | `IP` |
| **TAG_NAME** | Имя атрибута для итогового имени | `NAME` |
| **TAG_ICON** | Атрибут типа/иконки (на будущее) | `ICON` |
| **TAG_SERIAL** | Атрибут серийного номера (на будущее) | `SERIAL_NUMBER` |
| **NAME_FORMAT** | Шаблон итогового имени | `{cabinet}/{panel:02d}.{port}` |

Доступные подстановки в `NAME_FORMAT`: `{cabinet}`, `{panel}`, `{port}`.

## 5. Порядок работы

### 5.1 Экспорт и расчёт имён

Кнопка **«1. Экспорт и расчёт имён»**.

- Программа подключается к открытому чертежу AutoCAD.
- **Проверяет настройки:** конфликты портов между блоками, дубликаты.
- Считывает все блоки **всех включённых типов за один проход**.
- **Проверяет ёмкость шкафов**.
- Сортирует устройства и распределяет порты.
- Создаются файлы:
  - `export_final.csv` — полная таблица с результатами (с координатами X, Y),
  - `import.csv` — служебный файл для импорта.

### 5.2 Импорт в AutoCAD

Кнопка **«2. Импорт в AutoCAD»** — записывает сформированное имя в атрибут **NAME** каждого блока.

### 5.3 Генерация отчёта

Кнопка **«3. Сгенерировать отчёт»**.

Создаётся файл **«Отчёт по проекту.xlsx»** с **пятью листами**:

1. **Сводка по шкафам**
2. **Детали по панелям**
3. **Порты** (с автофильтром)
4. **Кабельный журнал**
5. **Кроссировочная таблица** (с автофильтром)

### 5.4 Полный цикл

Кнопка **«⚡ Полный цикл: экспорт → импорт → отчёт»** — одна кнопка для последовательного выполнения трёх шагов.

### 5.5 Чтение данных без изменений

Кнопка **«📖 Считать данные (без изменений)»**.

Программа читает блоки из чертежа и сохраняет в `export_final.csv`, **ничего не меняя в чертеже**. Полезно, если:
- Проект уже промаркирован, но нет `export_final.csv`.
- Нельзя перемаркировывать (например, временная схема).
- Нужны данные для отчётов и выносок стояков.

### 5.6 Доназначение нового оборудования

Кнопка **«🆕 Промаркировать новое оборудование»**.

Логика:
1. Программа читает все блоки из чертежа.
2. **Новыми** считаются блоки с `NAME = PLACEHOLDER_MARKER` (например, «Пустой»).
3. Строится карта занятых портов по старым блокам.
4. Новым блокам назначаются свободные порты (по правилам из раздела 4.6).
5. Формируется `import.csv` **только для новых блоков** — старые не трогаются.
6. Обновляется `export_final.csv`.

Дальше — обычный «Импорт в AutoCAD» и «Сгенерировать отчёт».

### 5.7 Заполнение выносок стояков мезонина

Вкладка **«Дополнительно»** → кнопка **«Заполнить выноски стояков мезонина»**.

Логика:
1. Программа читает `export_final.csv` (с координатами X, Y).
2. Собирает **рамки** (LWPOLYLINE) на слое, указанном в поле «Слой с рамками».
3. Для каждой мультивыноски (MLeader) берёт **точку стрелки** и находит рамку, в которой она лежит.
4. Внутри рамки определяет `(шкаф, этаж)` по большинству блоков.
5. Обновляет текст выносок:
   - **Этажи 2+:** `N UTP 4x2x0.5 / на отм. 0.000`
   - **Этаж 1 (сводная):** многострочный текст со всеми этажами.

Пример сводной выноски первого этажа:
```
46 UTP 4x2x0.5 с отм. 5 этажа
46 UTP 4x2x0.5 с отм. 4 этажа
46 UTP 4x2x0.5 с отм. 3 этажа
46 UTP 4x2x0.5 с отм. 2 этажа
50 UTP 4x2x0.5 с отм. +2.500
на отм. 0.000
```

**Важно:** для работы функции нужен слой с рамками. По умолчанию — `_WB_CAB_AREAS`. Имя слоя настраивается в поле «Слой с рамками».

## 6. Особенности кроссировочной таблицы

Порты патч-панели подключаются к портам коммутатора **не по принципу «порт в порт»**, а по специальной формуле:

- Порты патч-панели **1–24** → **нечётные** порты коммутатора (1, 3, 5, …, 47).
- Порты патч-панели **25–48** → **чётные** порты коммутатора (2, 4, 6, …, 48).

Пример:

| Патч-панель | Порт патч-панели | Коммутатор | Порт коммутатора |
|:-----------:|:----------------:|:----------:|:----------------:|
| 1 | 1 | 1 | 1 |
| 1 | 2 | 1 | 3 |
| 1 | 24 | 1 | 47 |
| 1 | 25 | 1 | 2 |
| 1 | 26 | 1 | 4 |
| 1 | 48 | 1 | 48 |

Формула:
- `1..24`: `порт_коммутатора = порт × 2 − 1`
- `25..48`: `порт_коммутатора = (порт − 24) × 2`

Свободные порты помечаются как **«резерв»**.

## 7. Пример настройки

Допустим, у вас есть блоки **камер** (`camera`) и **точек доступа** (`AP`).

- В таблице укажите:
  - `camera` → диапазоны `1-18,25-42`, отображаемое имя «Видеокамера», PoE включён.
  - `AP` → диапазоны `19-23,43-47`, отображаемое имя «Точка доступа Wi-Fi», PoE включён.
- Нажмите **«Полный цикл»**.

Если в проекте есть ещё и **розетки**, включите **Особый режим** и укажите `Socket_1p, Socket_RJ-45`.

## 8. Возможные ошибки и их решение

| Ошибка | Решение |
|--------|---------|
| **«Не удалось подключиться к AutoCAD»** | Запустите AutoCAD, откройте нужный чертёж и повторите операцию. |
| **«Не найдено ни одного блока с атрибутами»** | Проверьте, что имя блока в настройках совпадает с именем в чертеже, и что блоки имеют атрибуты (`ATTDISP` должна быть включена). |
| **«Обнаружены конфликты портов между блоками»** | Диапазоны портов разных блоков пересекаются. Отредактируйте диапазоны. |
| **«Блок включён одновременно в основном и особом режиме»** | Снимите галочку в таблице основных блоков или уберите его из поля «Имена блоков» особого режима. |
| **«Не хватает портов в шкафах»** | Увеличьте `MAX_PANELS_PER_CABINET` или проверьте пропуски портов. |
| **«Файл ... не найден. Сначала запустите экспорт»** | Перед импортом или отчётом сначала выполните экспорт или считайте данные. |
| **«В export_final.csv нет колонок X, Y»** | Файл создан старой версией `assign_names.py`. Обновите программу и повторите экспорт, либо используйте «Считать данные (без изменений)». |
| **«Permission denied» при генерации отчёта** | Закройте файл «Отчёт по проекту.xlsx», если он открыт в Excel. |
| **«На слое ... нет рамок»** | Проверьте имя слоя с рамками в настройках вкладки «Дополнительно». |

## 9. Примечания

- Программа работает **только с открытым AutoCAD** и активным чертежом.
- Все файлы с результатами создаются в той же папке, где находится `Autocad_tool.exe`.
- Атрибуты MAC и IP можно изменить в GUI (раздел «Атрибуты блоков и шаблон имени»).
- Для дробных этажей (например, `1.5`) сортировка работает корректно.
- Особый режим — двумя способами: начать с новой панели или продолжить с последней.
- В кроссировочной таблице столбцы **IP адрес** и **MAC адрес** заполняются подрядчиком после монтажа (в отчёте — прочерк `-`).
- Заполнение выносок стояков работает **через рамки**: одна рамка = один шкаф на одном этаже. Стрелка выноски должна находиться внутри соответствующей рамки.

## 📦 Установка и требования

**Для запуска exe-версии:**  
Ничего дополнительно устанавливать не нужно. Достаточно перенести папку с `Autocad_tool.exe`, `config.py` и `_internal/` на компьютер с установленным AutoCAD.

**Для запуска из исходного кода:**
```bash
pip install -r requirements.txt
python main_ui.py
```

**requirements.txt:**
```
pandas
pywin32
openpyxl
```
