## 1. Назначение программы

Программа автоматически нумерует блоки в AutoCAD (камеры, точки доступа, розетки, разъёмы RJ-45 и т.д.) в соответствии с патч-панелями. Для каждого устройства создаётся уникальное имя, например:

```
8.1A1/01.4
```

где:
- `8.1A1` — номер шкафа,
- `01` — номер патч-панели,
- `4` — номер порта на панели.

**Ключевая особенность версии 4.x** — все типы блоков обрабатываются **за один запуск**. Раньше приходилось запускать программу отдельно для каждого типа блока (камеры, затем AP, затем розетки), теперь достаточно задать все настройки один раз.

Для работы необходимо, чтобы каждый блок имел три атрибута:

| Атрибут | Назначение |
|---------|-----------|
| **NAME** | Итоговое имя (заполняется автоматически) |
| **MAC** | Временное поле для номера шкафа (заполняется вручную перед обработкой) |
| **IP** | Временное поле для номера этажа (заполняется вручную перед обработкой) |

> **Примечание:** вместо MAC и IP можно использовать другие атрибуты — они настраиваются во вкладке «Настройки» программы (раздел «Атрибуты блоков и шаблон имени»). По умолчанию используются именно MAC и IP.

## 2. Подготовка чертежа AutoCAD

Перед запуском программы:

1. Откройте нужный чертёж в AutoCAD.
2. Убедитесь, что все блоки имеют атрибуты **MAC** и **IP**.
   - В **MAC** укажите имя шкафа (например, `8.1A1`).
   - В **IP** укажите номер этажа (целое число, например `1`, или дробное, например `1.5` — для сортировки внутри этажа).
3. Заполните эти атрибуты для всех блоков (можно выделить группу блоков и ввести значения через палитру свойств `Ctrl+1`).
4. Сохраните чертёж.

## 3. Запуск программы

Запустите файл `Autocad_tool.exe`. Откроется окно с двумя вкладками: **«Настройки»** и **«Выполнение»**.

## 4. Настройки программы

Все настройки задаются в соответствующих полях. При нажатии на любую кнопку («Экспорт», «Импорт», «Отчёт» или «Полный цикл») настройки **автоматически сохраняются**. Также автосохранение происходит при закрытии окна программы.

### 4.1 Таблица блоков

Вместо одного поля «Имя блока» — **таблица на 5 строк**. В каждой строке:

| Вкл | Имя блока | Отображаемое имя | Диапазоны портов | PoE |
|:---:|-----------|------------------|------------------|:---:|
| ☑ | camera | Видеокамера | 1-18,25-42 | ☑ |
| ☑ | AP | Точка доступа Wi-Fi | 19-23,43-47 | ☑ |
| ☐ | Socket_1p | Розетка | 1-18,25-42 | ☐ |
| ☐ | Socket_RJ-45 | Разъём RJ-45 | 1-18,25-42 | ☐ |
| ☐ | *(пустая строка)* | | | |

- **Галочка** — включает или отключает блок из обработки.
- **Имя блока** — точное имя блока в AutoCAD (`camera`, `AP` и т.д.). Можно выбрать из выпадающего списка или ввести своё.
- **Отображаемое имя** — человекочитаемое имя для кабельного журнала и кроссировочной таблицы (например, «Видеокамера», «Точка доступа Wi-Fi»).
- **Диапазоны портов** — какие порты на патч-панели может занимать этот блок.
- **PoE** — получает ли оборудование этого типа питание PoE. Влияет на столбец «Питание» в кроссировочной таблице.

Кнопка **«+ Добавить строку»** снизу таблицы позволяет добавить дополнительные строки, если в проекте больше 5 типов блоков.

### 4.2 Формат диапазонов портов

Диапазоны и отдельные порты через запятую:

- `1-18,25-42` — порты с 1 по 18 и с 25 по 42,
- `19-23,43-47` — порты с 19 по 23 и с 43 по 47,
- `1,5,10-15` — отдельные порты 1, 5 и диапазон 10–15.

### 4.3 Пропуски портов

Используется, если некоторые порты на конкретных патч-панелях уже заняты другим оборудованием.

**Формат:** каждая строка содержит три части:

```
шкаф, номер_панели, список_портов
```

Примеры:

```
8.1A1,1,25-29
8.1A1,2,25-30,40
```

Это означает:
- в шкафу `8.1A1` на первой панели пропустить порты 25–29,
- в шкафу `8.1A1` на второй панели пропустить порты 25–30 и порт 40.

Поле поддерживает **копирование и вставку** (правой кнопкой мыши). Можно скопировать пример из жёлтой подсказки и отредактировать под себя.

### 4.4 Максимум патч-панелей в шкафу

Общее поле с предзаполненным значением `20`. Программа не будет искать панели с номером больше указанного.

### 4.5 Особый режим

Особый режим нужен для блоков, которые должны маркироваться **не вместе со всеми**, а **после основных**. Типичный пример — розетки и разъёмы RJ-45.

Параметры:

- **Галочка «Обрабатывать блоки особого режима»** — включает режим.
- **Имена блоков (через запятую)** — какие блоки обрабатывать в особом режиме и в каком порядке. Например: `Socket_1p, Socket_RJ-45`.
- **Диапазоны портов** — какие порты могут занимать эти блоки. Например: `1-23,25-47`.
- **Галочка «Продолжить с последней патч-панели»** — если включена, особый режим начинается с той же панели, где закончились основные блоки, а не с новой.
- **Поле «Отступить от последнего порта»** — сколько портов пропустить после последнего занятого (например, оставить 2 порта свободными перед розетками).

### 4.6 Атрибуты блоков и шаблон имени

В самом низу вкладки «Настройки» — раздел для тонкой настройки программы:

| Параметр | Назначение | По умолчанию |
|----------|-----------|--------------|
| **TAG_CABINET** | Имя атрибута с номером шкафа | `MAC` |
| **TAG_FLOOR** | Имя атрибута с номером этажа | `IP` |
| **TAG_NAME** | Имя атрибута для итогового имени | `NAME` |
| **TAG_ICON** | Атрибут типа/иконки (на будущее) | `ICON` |
| **TAG_SERIAL** | Атрибут серийного номера (на будущее) | `SERIAL_NUMBER` |
| **NAME_FORMAT** | Шаблон итогового имени | `{cabinet}/{panel:02d}.{port}` |

Все поля с выпадающими списками — можно выбрать стандартное значение из списка (`MAC`, `IP`, `NAME`, `ICON`, `SERIAL_NUMBER`) или вписать своё.

Доступные подстановки в `NAME_FORMAT`:
- `{cabinet}` — шкаф,
- `{panel}` — номер панели,
- `{port}` — номер порта.

## 5. Порядок работы

Всегда выполняйте шаги по порядку.

### 5.1 Экспорт и расчёт имён

Кнопка **«1. Экспорт и расчёт имён»**.

- Программа подключается к открытому чертежу AutoCAD.
- **Проверяет настройки:** нет ли пересечения портов между блоками, нет ли дубликата (блок включён и как основной, и как особый).
- Считывает все блоки **всех включённых типов за один проход**, а также значения атрибутов **MAC** (шкаф) и **IP** (этаж).
- **Проверяет ёмкость шкафов** — хватает ли портов для всех устройств каждого типа.
- Сортирует устройства по шкафам, этажам и положению на чертеже (сверху вниз, слева направо).
- Распределяет порты по патч-панелям: сначала для основных блоков, затем (если включён) для блоков особого режима.
- Создаются файлы:
  - `export_final.csv` — полная таблица с результатами (единая для всех блоков),
  - `import.csv` — служебный файл для импорта.
- В окне лога отображается прогресс и итоги по каждому шкафу.

### 5.2 Импорт в AutoCAD

Кнопка **«2. Импорт в AutoCAD»**.

- Программа считывает файл `import.csv`.
- По уникальному идентификатору (Handle) находит каждый блок в AutoCAD и записывает сформированное имя в атрибут **NAME**.
- После импорта чертёж автоматически обновляется.
- В логе отображается количество обработанных и изменённых блоков.

### 5.3 Генерация отчёта

Кнопка **«3. Сгенерировать отчёт»**.

Создаётся единый файл **«Отчёт по проекту.xlsx»** с **пятью листами**:

1. **Сводка по шкафам** — для каждого шкафа: количество устройств, количество патч-панелей, детали по каждой панели. Панели выводятся на отдельных строках.
2. **Детали по панелям** — для каждой панели шкафа: занятые порты (диапазонами), количество портов, тип оборудования.
3. **Порты** — для каждой панели перечислены ВСЕ порты (1–48) с указанием имени устройства, этажа и типа оборудования. Есть автофильтр по всем столбцам.
4. **Кабельный журнал** — таблица с трассой каждого кабеля: позиция, обозначение кабеля, начало (шкаф, панель, порт), конец (тип оборудования и имя), тип кабеля, длина (прочерк, заполняет подрядчик), примечание.
5. **Кроссировочная таблица** — подключения портов патч-панели к портам коммутатора с типом оборудования, маркировкой, этажом, питанием (PoE / нет), IP и MAC. Есть автофильтр по всем столбцам.

Все листы отчёта оформлены единообразно: цветные шапки, границы ячеек, аккуратные ширины столбцов.

Отчёт не изменяет чертёж и нужен только для контроля и передачи данных.

### 5.4 Полный цикл

Кнопка **«⚡ Полный цикл: экспорт → импорт → отчёт»**.

Одна кнопка, которая последовательно выполняет все три шага за один раз. Удобно, если нужно быстро получить готовый результат.

## 6. Особенности кроссировочной таблицы

Порты патч-панели подключаются к портам коммутатора **не по принципу «порт в порт»**, а по специальной формуле, чтобы использовать короткие патч-корды и сохранить эстетику монтажа:

- Порты патч-панели **1–24** → **нечётные** порты коммутатора (1, 3, 5, …, 47).
- Порты патч-панели **25–48** → **чётные** порты коммутатора (2, 4, 6, …, 48).

Пример:

| Патч-панель | Порт патч-панели | Коммутатор | Порт коммутатора |
|:-----------:|:----------------:|:----------:|:----------------:|
| 1 | 1 | 1 | 1 |
| 1 | 2 | 1 | 3 |
| 1 | 24 | 1 | 47 |
| 1 | 25 | 1 | 2 |
| 1 | 26 | 1 | 4 |
| 1 | 48 | 1 | 48 |

Формула расчёта:

- Если порт патч-панели `1..24`: `порт_коммутатора = порт × 2 − 1`
- Если порт патч-панели `25..48`: `порт_коммутатора = (порт − 24) × 2`

Свободные порты помечаются как **«резерв»**.

## 7. Пример настройки

Допустим, у вас есть блоки **камер** (имя `camera`) и **точек доступа** (имя `AP`).

- В таблице укажите:
  - `camera` → диапазоны `1-18,25-42`, отображаемое имя «Видеокамера», галочка включена, PoE включён.
  - `AP` → диапазоны `19-23,43-47`, отображаемое имя «Точка доступа Wi-Fi», галочка включена, PoE включён.
- В пропусках портов (если есть занятые) укажите нужные строки.
- Нажмите **«Полный цикл»** — программа сама выполнит экспорт, импорт и построит отчёт.

Если в проекте есть ещё и **розетки**, включите **Особый режим**, укажите в нём блоки `Socket_1p, Socket_RJ-45` и диапазоны портов, а в таблице основных блоков уберите галочку PoE для розеток. Розетки будут промаркированы после камер и AP, на новых панелях (или на последней — если включена галочка «Продолжить с последней патч-панели»).

## 8. Возможные ошибки и их решение

| Ошибка | Решение |
|--------|---------|
| **«Не удалось подключиться к AutoCAD»** | Запустите AutoCAD, откройте нужный чертёж и повторите операцию. |
| **«Не найдено ни одного блока с атрибутами»** | Проверьте, что имя блока в настройках точно совпадает с именем в чертеже, и что блоки имеют атрибуты (команда `ATTDISP` должна быть включена). |
| **«Обнаружены конфликты портов между блоками»** | Диапазоны портов разных блоков пересекаются. Отредактируйте диапазоны, чтобы они не пересекались. |
| **«Блок включён одновременно в основном и особом режиме»** | Один и тот же блок нельзя обрабатывать дважды. Снимите галочку в таблице основных блоков или уберите его из поля «Имена блоков» особого режима. |
| **«Не хватает портов в шкафах»** | Устройств больше, чем доступных портов при заданном максимуме панелей. Увеличьте `MAX_PANELS_PER_CABINET` или проверьте пропуски портов. |
| **«Файл ... не найден. Сначала запустите экспорт»** | Перед импортом или отчётом необходимо сначала выполнить экспорт. |
| **«Permission denied» при генерации отчёта** | Закройте файл «Отчёт по проекту.xlsx», если он открыт в Excel, и повторите. |

## 9. Примечания

- Программа работает **только с открытым AutoCAD** и активным чертежом.
- Все файлы с результатами создаются в той же папке, где находится `Autocad_tool.exe`.
- Если в ваших блоках атрибуты MAC и IP заняты, можно изменить их имена в GUI (раздел «Атрибуты блоков и шаблон имени») — не нужно править `config.py` вручную.
- Для дробных этажей (например, `1.5`) сортировка работает корректно: сначала обрабатываются устройства с `1.0`, затем с `1.5`. Это удобно, если нужно разделить порядок маркировки внутри одного этажа.
- При использовании пропусков портов, если для какой-то панели все порты пропущены, программа автоматически переходит к следующей панели.
- Особый режим можно использовать двумя способами:
  - **Начать с новой панели** (галочка «Продолжить с последней» снята) — блоки особого режима идут на отдельных панелях.
  - **Продолжить с последней панели** (галочка включена) — блоки особого режима дополняют последнюю панель основных блоков, с возможностью оставить несколько свободных портов между группами.
- Столбцы **IP адрес** и **MAC адрес** в кроссировочной таблице заполняются подрядчиком после монтажа — в отчёте они помечены прочерком `-`.

## 📦 Установка и требования

**Для запуска exe-версии:**  
Ничего дополнительно устанавливать не нужно. Достаточно перенести папку с `Autocad_tool.exe`, `config.py` и `_internal/` на компьютер с установленным AutoCAD.

**Для запуска из исходного кода:**
```bash
pip install -r requirements.txt
python main_ui.py
```

**requirements.txt:**
```
pandas
pywin32
openpyxl
```
